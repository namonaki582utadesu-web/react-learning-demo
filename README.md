# React Learning Shooter

Reactの学習を目的として制作した、シューティングゲーム風の学習アプリです。

問題に回答しながらゲーム感覚で学習できるよう、「計算」「漢字」「英単語」などの学習モードを選択できる構成にしています。

本プロジェクトでは、Reactの状態管理やイベント処理、TypeScriptによる型定義などを実際のゲーム形式に落とし込むことを目的としました。

------------------------------------------------------------------------

## 🎮 Overview

学習問題をシューティングゲーム風の画面上で出題し、選択肢から回答してゲームを進めていきます。

現在は学習用プロトタイプとして、主に計算問題のゲームフローを実装しています。

### Game Flow

``` text
ゲームモード選択
      ↓
レベル選択
      ↓
問題出題
      ↓
4択から回答
      ↓
正解・不正解を表示
      ↓
次の問題
      ↓
全5問
      ↓
結果表示
```

## ✨ Features

### ゲームモード選択

以下の学習モードを選択できる構成にしています。

-   計算
-   漢字
-   英単語

現在は計算モードを中心に実装しています。

### レベル選択

計算モードではレベルを選択してゲームを開始できます。

-   LEVEL 1
-   LEVEL 2
-   LEVEL 3

学習問題のレベルをTypeScriptの型として管理しています。

### ランダム問題生成

計算問題は固定値ではなく、ゲーム開始時や次の問題へ進む際にランダム生成します。

例：

``` text
3 + 7 = ?
8 + 4 = ?
5 + 9 = ?
```

毎回異なる問題になるため、同じ問題を繰り返しプレイする構成にならないようにしています。

### 4択回答

生成された問題に対して4つの選択肢を表示し、選択した回答が正解かどうかを判定します。

### 問題進行管理

1回のゲームで5問を出題します。

``` text
第1問 / 5問
第2問 / 5問
第3問 / 5問
...
第5問 / 5問
```

最終問題まで回答すると結果画面へ遷移します。

### スコア表示

正解数をカウントし、ゲーム終了時に結果を表示します。

``` text
5 / 5
全問正解！
```

## 📚 React Learning Points

このプロジェクトでは、Reactの基本機能を実際のアプリケーションとして組み合わせることを目的としました。

### State Management

`useState`を使用してゲームの状態を管理しています。

``` text
gameMode
gameLevel
question
questionNumber
correctCount
answerResult
gameFinished
```

ゲームの進行に応じてStateを更新し、画面を切り替える構成にしています。

### Event Handling

ボタン操作をReactのイベントとして処理しています。

``` text
ゲームモード選択
↓
レベル選択
↓
回答
↓
次の問題
↓
結果表示
```

### Conditional Rendering

ゲームの状態に応じて表示する画面を切り替えています。

``` text
ゲームモード選択画面
↓
レベル選択画面
↓
問題画面
↓
結果画面
```

### TypeScript

ゲームモードや問題レベル、問題データなどをTypeScriptで型定義しています。

これにより、ゲーム状態や問題データの扱いを明確にしています。

### Random Data Generation

計算問題をランダム生成することで、固定された問題データだけに依存しない仕組みを実装しています。
